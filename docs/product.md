# 产品与交互

Cataland 将岛屿建设、资源交换与卡牌决策放在同一张桌面棋盘上。朋友通过局域网进入一间房间，由一台电脑主持对局。每名玩家拥有自己的手牌视角，公共棋盘则展示大家共同建设的岛屿。

桌面应用面向 Windows、macOS 和 Linux。基础规则与城市与骑士分别构成完整玩法，人数变化对应双人中立势力、标准对局和五至六人的双玩家回合。具体数值与卡牌效果见[游戏规则](rules.md)。

## 体验结构

游戏中的空间决策发生在棋盘上：建筑落在哪个路口、道路朝哪里延伸、骑士如何通过道路移动，都通过对应位置直接选择。资源、卡牌、交换和城市发展由棋盘周围的面板承载。

界面把三个问题放在显眼位置：当前由谁行动、正在完成什么、可以选择哪些操作。涉及其他玩家的选择时，同一个对局仍展示正在进行的步骤，选择者看到自己的选项，其他人看到执行者与动作说明。

自然地形承担环境氛围，数字、建筑轮廓、玩家颜色和高亮承担规则信息。海岸、屋顶与卡牌插画形成统一的桌游观感。动效表现一次状态变化的发生与结束，静态棋局适合阅读和思考。

## 首页

首页包含游戏介绍、身份设置、创建房间、加入房间与继续游戏。岛屿主视觉使用应用图标的聚落插画，名称、副标题与正文随本机语言设置显示。

### 玩家身份

玩家填写名称并选择一种颜色。六种颜色为陶红、海蓝、麦金、鸢紫、莓粉、松绿。名称与颜色保存在本机，下次进入应用时继续使用。

姓名用于显示，席位关联使用本机生成的身份标识。重新连接时，同一身份回到原席位。房间中已有玩家占用某个颜色时，新玩家分配到可用颜色；大厅中的颜色选择也会标出占用情况。

### 创建房间

创建表单提供房间名称、基础规则或城市与骑士，以及 2–6 人的人数设置。这里的人数是房间容量，实际开局人数由已加入的玩家席位决定。

房间创建后进入大厅，由本机应用同时提供房间服务。主机地址在大厅中展示，局域网其他电脑也能在房间列表中发现它。

### 加入房间

局域网列表展示房间名称、玩法、已占席位数和容量。已经开局的房间显示观战提示。点击房间即可连接；地址输入框接受主机名或 IP 与端口，例如 `192.168.1.10:42000`。

最近加入记录保留房间名称和地址。同一房间再次被发现时，连接使用发现到的新地址，因此房主恢复房间后改变端口也可以继续加入。

### 继续游戏

本机创建的房间按保存时间展示，列表中包含房间名、参与者和时间。进行中的存档重新开放房间；已结束的存档标注「已结束 · 查看对局」，打开本地对局记录。

## 房间大厅

大厅展示房间设置、玩家席位、颜色、连接情况、准备状态、观战者和聊天。房主可以修改房间名称、玩法、容量与起始玩家。起始玩家可以随机选择，也可以指定已经入座的玩家。

修改房间设置后，其他玩家重新准备。至少两名玩家入座，且所有玩家席位都已连接并准备时，由房主开始。游戏依据实际人数生成地图和相应玩法。

玩家可在大厅调整自己的名称与颜色。普通玩家通过准备按钮表达开局意愿，房主执行开始操作。观战者可以查看大厅和参与聊天。

## 对局页面

### 顶部信息

页面标题展示房间名称、玩法、获胜分数和回合编号。五至六人额外显示当前是主回合还是配对行动。

玩家栏按座位排列，展示颜色、名字、当前行动者、分数、资源与商品总数、卡牌总数、道路长度及军队或防御力。自己的分数包含隐藏胜利点，对手显示公开分数。最长道路与最大军队的持有者带奖励标识，断线玩家带连接状态提示。

双人中立势力也出现在玩家栏，展示名称、颜色和道路长度，方便观察其道路竞争。

### 棋盘与导航

六种地形在棋盘上有独立轮廓和插画。数字牌以点数和概率圆点表示产出机会，6 与 8 使用醒目的数字颜色。港口在海岸外侧显示船只、资源名称和兑换比例。

村庄、城市、城墙、大都会、骑士、强盗与商人按实际状态显示。玩家颜色用于道路、屋顶与骑士标记；城墙与大都会有额外形状。未激活骑士倾斜放置，激活骑士直立，并显示等级标记。

棋盘支持左键或中键拖动、滚轮缩放、放大缩小按钮和完整棋盘归位。滚轮以指针位置为缩放中心，按钮以视区中心为缩放中心。拖动发生一定距离后视为移动棋盘，单击则选择当前位置。

建造工具覆盖在棋盘顶部，导航位于棋盘角落。工具之间的空白仍属于可拖动的棋盘区域。

### 选择动作

玩家点击建造类别后，对应路口或道路高亮。卡牌和其他需要地图位置的效果直接高亮可选地块、顶点或道路。没有地图目标的动作在按钮或侧栏中选择。

这些选项由规则引擎提供。界面使用同一份动作数据展示费用、按钮和位置，因此手牌变化、道路阻断或回合切换后，选项会随游戏状态变化。

### 手牌与交易

自己的资源和商品显示在棋盘下方，卡牌插画与数量同时呈现。旁边列出剩余道路、村庄与城市数量。基础模式展示五种资源，城市与骑士增加三种商品。

银行交易面板根据自己拥有的港口、商人、商船队和城市能力展示汇率。玩家交易通过给出、索取两组牌发出报价，其他玩家可以回应，发起者选择同意者成交。

同种发展卡和进步卡合并展示数量，每张卡同时显示名称与效果。购买回合、使用次数和阶段决定当前能否出牌。卡牌带来的进一步选择在动作面板中完成。

### 城市、骑士与海上事件

城市发展面板展示贸易、政治、科学等级、下一次发展费用、三级能力和大都会归属。城墙与城市位置仍通过棋盘选择。

骑士面板展示自己的骑士，提供当前可用的激活、晋升、移动、驱逐强盗和双人交回操作。招募位置、移动目的地和被驱逐后的重新安置通过棋盘完成。

海上事件面板展示野蛮人航程、来袭强度、岛屿防御力、来袭次数及三摞进步卡余量。守护者分数、宪法和印刷术在公开成就中展示。

### 等待其他玩家选择

弃牌、婚礼、商业港、叛变和野蛮人城市损失会将选择交给相应玩家。选择者看到牌数、可选对象或位置；其他玩家继续看到相同棋盘及当前步骤的说明。

多人同时弃牌时，响应面板列出全部参与者和「选择中／已完成」状态。已经提交的玩家仍留在列表里，直到所有参与者完成，随后继续强盗或下一项结算。

### 事件与聊天

侧栏可以切换游戏记录和聊天。游戏记录默认展示最近 60 条，点击「更早的记录」继续展开历史。记录包含公开事件及属于自己的私有事件，具体手牌变化按事件的可见对象展示。

聊天包含发言人和正文，在大厅与棋局中使用同一份房间历史。聊天消息独立更新，棋盘仍停留在当前游戏状态。观战者可以参与实时聊天。

## 断线、退出与存档

连接中断时显示连接面板，原棋局留在底下。玩家可以重新连接或返回首页。房间重新出现在局域网中时，应用也会尝试连接相同房间。

席位保存在房主的房间数据中。断线玩家仍占有自己的建筑、手牌和待完成选择；需要该玩家行动时，游戏停留在相应步骤。

房主返回首页或关闭应用后，房间服务结束。每次有效操作已经保存到房主电脑，之后从首页打开该存档即可继续。恢复房间沿用原房间标识和席位，新监听地址通过局域网发现发布。

同一次连接会话内，重连追加错过的事件与聊天。重新启动客户端后则重新读取可见历史，并使用持久保存的身份返回席位。

## 胜利与对局记录

达到目标分数后，界面展示获胜者和最终棋盘，公开每名玩家的最终总分。已连接的房间仍可查看结果和聊天。

首页打开已结束的存档时进入本地浏览。这个视角包含最终棋盘、公开分数、公开事件和历史聊天，页面以「对局记录」标识，聊天区域只展示历史内容。

对局记录是最终状态与文字事件的浏览。棋盘停留在最终布局，事件列表供玩家回顾发展经过。

## 设置与反馈

| 设置 | 选择与作用 |
| --- | --- |
| 语言 | 简体中文、英文；分别作用于各自客户端 |
| 界面缩放 | 75%、90%、100%、110%、125%、150% |
| 动画强度 | 关闭、轻柔、标准 |
| 主音量 | 统一调节全部声音 |
| 背景音乐 | 岛屿主题乐循环音量 |
| 游戏音效 | 点击、骰子、建造、卡牌与事件音量 |
| 环境声音 | 海岸环境循环音量 |
| 显示器 | 将窗口移动到选择的显示器 |
| 显示模式 | 窗口、全屏，F11 可以即时切换 |

设置在点击「应用设置」后生效，取消则关闭正在编辑的设置。窗口大小与位置由桌面窗口状态保存。

默认窗口为 1440 × 960，最小窗口为 960 × 640。界面使用系统字体，按钮和导航配有文本或可访问名称，地图对象通过颜色、轮廓和相应面板共同表达含义。

界面语言包括按钮、卡牌、规则提示、事件、绘制异常与音频加载错误。玩家名称、房间名称和聊天内容按原文展示。错误采用页面通知或所属面板中的提示，玩家可以关闭通知并继续观察当前状态。

首次鼠标或键盘交互会启动声音系统。音乐、海岸声和游戏反馈分别控制音量。动画和音效响应新的游戏变化，首次进入或查看存档时展示当时的棋局。
